# Assignment 2: Full-Stack Login and Signup
Basic Sign in and Login Implementation. 

Exceptions:
* One or more required Signup or Login fields are empty.
* The requested username already exists.
* The username does not exist.
* A new user is successfully created.
* The password or credentials are incorrect.
* A database or server error occurs.

# Assignment 3: Projects and Project Memberships
Users are now able to create and manage projects, assign and unassign users to groups.

Exceptions:
* One or more required project fields are empty.
* The project status or Project Lead is invalid.
* The project, user, or membership was not found.
* The user is already a member of the project.
* The Project Lead cannot be removed from the project.
* A database or server error occurs.

# Assignment 4: User Stories and Project Backlog
Users will be able to add stories to existing projects, track progress, and assign work to project members.

Exceptions:
* The title or description is blank, or the priority or status is not an allowed value.
* A project or story identifier is invalid.
* The project or story was not found, or the story does not belong to the selected project.
* The assigned user is not a member of the project.
* A member with assigned stories cannot be removed from the project.
* A database or server error occurs.
